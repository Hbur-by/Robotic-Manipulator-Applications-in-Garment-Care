# identify · 通道识别固件

**干什么用的**：全拆重装之后，7 个舵机插回 PCA9685 时「不确定哪个插在哪个通道」。主固件一上电就 `resetAll()` 归位，插错通道的舵机会朝别人的角度冲；这个固件**上电不归位**，所有通道默认无脉冲（舵机是松的），只有你主动选中并激活某个通道，它才动 —— 于是可以「插一个、试一个、记一个」。

## 烧录

```powershell
# 在仓库根（D:\hbur\rmagc）
pio run -d code_v0.2/identify -t upload
pio device monitor -b 115200
```

> 与主固件共用同一套 N16R8 内存配置（`qio_opi` / `opi` / 16 MB），烧完再烧回主固件不会有残留问题。

## 用法（串口 115200，单字符命令，不用回车）

| 键 | 作用 |
|---|---|
| `0`–`6` | 选中通道（0–5 = 关节，6 = 滑轨） |
| `+` / `-` | 选中通道 ±5°（**第一次按下时该通道才开始输出**） |
| `m` | 选中通道回中位 90° |
| `x` | 释放选中通道（停脉冲 → 舵机变松，可以安全拔插） |
| `r` | 释放全部通道 |
| `p` | 打印各通道状态 |
| `t` / `g` / `b` | 滑轨 前进 / 后退 / 停（只对 CH6） |
| `?` | 帮助 |

## 推荐流程

1. 先**不插任何舵机**，上电，确认串口打印 `I2C 扫描 0x40 : 找到`。
2. 把 1 个舵机插到 **CH0**（信号线朝丝印 `S`）。
3. 输入 `0` → `m`：看**哪个关节**动了，就是这个通道的归属。
4. `+` / `-` 各按两下，确认方向和行程，记到 `硬件确认.md` 的「S3.6 试完把结果填这里」表里。
5. `x` 释放 → 拔下这个舵机 → 换下一个通道，重复 2–4。
6. 7 个都记完 → 按记录重新按正确通道插好 → 烧回主固件 `code_v0.1/firmware`。

## 判定

- 选中某通道、按 `m` 后**没有任何关节动** → 该通道没插舵机，或舵机坏了/线断。
- 动了但**不是你以为的那个关节** → 通道插错，按实测记录改到正确通道；**不要改代码**。
- 方向反了（`+` 让它朝反方向走）→ 通道没错，是舵机装配方向反了；在代码里取反，或物理上换个安装角。
- `+` 时听到**持续吱吱声、关节不动** → 顶到机械限位了，立刻按 `x` 释放。

## 注意

- 全程把手放在**插排开关**上（本机还没有正式急停，见 `硬件确认.md` S9）。
- 拔插舵机前先按 `x`（该通道停脉冲），别带电硬拔。
- CH6 是连续旋转舵机，**没有角度概念**：`+`/`-` 对它无效，只能用 `t`/`g`/`b`。
