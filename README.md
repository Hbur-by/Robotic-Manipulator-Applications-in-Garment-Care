# Robotic-Manipulator-Applications-in-Garment-Care
RMAGC — a 6-axis robot arm on a sliding rail for part-level garment care. YOLOv8 vision guides targeting of collars/underarms/cuffs. ESP32-S3 drives servos (PCA9685) and hosts WiFi web control. Quickchange end effectors:dehumidifier, UV sterilizer, aroma mister, gripper. 90% success rate, 8.8s response, target BOM ≤¥500.
