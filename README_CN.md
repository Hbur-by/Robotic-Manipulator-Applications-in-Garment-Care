## 一、项目概述

### 1.1 摘要

本作品"焕衣智联"针对传统衣物护理设备功能固化、无法定位衣物部位靶向作业、工具拆装繁琐、多工序适配能力弱的行业痛点，设计了一套基于可移动平台与多自由度机械臂的一体化智能衣物管家机器人系统。系统通过标准化快换接口实现熨烫、除湿、UV消毒、香薰雾化、夹持抓手等多功能末端执行器的快速切换，结合视觉识别与闭环控制，可对衣物领口、腋下等关键部位进行精准护理。

省赛阶段已搭建六轴金属机械臂实际平台，完成运动学建模与基础视觉伺服验证，闭环成功率达90%。国赛阶段将进一步集成YOLOv8目标检测与实时视觉引导，实现从"预设动作"到"视觉驱动"的完整闭环，验证系统的技术可行性与产品化潜力。

**关键词**：智能衣柜；衣物护理机器人；机械臂；快换接口；视觉伺服；YOLOv8

### 1.2 项目背景与痛点分析

随着智能家居技术的发展和消费升级，用户对衣物护理的需求已从基础除湿向精细化、智能化方向转变。现有衣物护理装置主要为固定式除湿和香薰设备，存在以下局限：

| 痛点 | 具体表现 | 影响 |
|------|---------|------|
| 功能固化 | 末端执行结构固定，多为螺栓刚性连接，拆装繁琐 | 无法快速切换熨烫、消毒、除湿、夹持等功能 |
| 定位粗放 | 无法对领口、腋下等关键部位实现靶向护理 | 干燥/消毒效果不均匀 |
| 作业离散 | 电气与气路管路分散，多工序连续作业能力弱 | 护理流程割裂，效率低 |
| 成本高昂 | 市面主流设备（如LG Styler）售价数千元 | 普通消费群体难以接受 |

### 1.3 竞品对比分析

| 维度 | LG Styler | 传统除湿衣柜 | 本作品（RMAGC） |
|------|-----------|-------------|-----------------|
| 价格区间 | ¥5,000-10,000 | ¥500-2,000 | 目标BOM ≤ ¥500 |
| 功能 | 蒸汽除味+烘干 | 基础除湿 | 除湿+香薰+UV消毒+熨烫+智能寻衣 |
| 部位级护理 | 无 | 无 | 机械臂精准定位 |
| 末端可换 | 无 | 无 | 快换接口+多末端 |
| 视觉引导 | 无 | 无 | YOLOv8视觉识别 |
| 智能推荐 | 无 | 无 | 大模型穿搭推荐（预留接口） |

### 1.4 项目目标

本项目旨在研制一款可主动检测衣物状态、依托可移动平台与可延长机械臂实现部位级自动护理的智能衣物管家机器人。系统具备以下核心能力：

1. **精准定位护理**：通过视觉识别定位衣物关键部位（领口、腋下、袖口），驱动机械臂抵达目标区域执行护理操作。
2. **多功能柔性换装**：采用标准化快换接口，支持熨烫、除湿、UV消毒、香薰雾化、夹持抓取等末端执行器的快速切换。
3. **智能数据联动**：自动记录衣物类别、颜色、位置信息，支持智能寻衣与穿搭推荐。
4. **全流程自动化**：完成取放→护理→收纳全流程作业，减少人工干预。

### 1.5 目标场景与用户群体

**安装场景**：
- 阳台晾衣处（单侧直线布局 → 单滑轨方案）
- 衣柜上方（宽1.2m~1.8m → 龙门双轴方案）
- 墙面挂装（小空间 → 壁挂式方案）
- 洗衣店/干洗店吊挂区（批量衣物护理 → 滑轨或移动小车方案）
- 服装零售店（衣物展示护理 → 移动小车方案）
- 酒店布草间（床品批量护理 → 龙门或移动方案）

**目标用户**：
- **C端**：城市白领、高端人士等对生活品质有要求但时间有限的群体
- **B端**：洗衣店、服装店、酒店等需要批量衣物护理的商业客户

## 二、系统总体设计

### 2.1 系统架构

本系统采用树莓派作为上位机（使用电脑代替）+下位机（ESP32-S3）分层架构，各模块协同工作：

- **感知层**：USB摄像头（国赛）/ OV2640（省赛验证）负责采集衣物图像，作为视觉识别的输入源
- **决策层**：笔记本运行OpenCV与YOLOv8模型，完成目标检测→坐标计算→角度查表→指令生成，通过串口下发至下位机
- **执行层**：ESP32-S3接收指令，驱动PCA9685产生PWM信号，控制6轴机械臂舵机与滑轨电机协同运动；同时管理继电器（风扇/除湿模块开关）
- **交互层**：笔记本/手机通过WiFi访问ESP32-S3内置网页服务器，实时监控状态与下发指令

### 2.2 系统工作步骤

1. 摄像头实时采集工作区域图像（感知层）
2. YOLOv8目标检测 → 识别衣物位置与类别（决策层）
3. 计算目标中心像素坐标 (u, v)
4. 通过标定查找表 ↔ 物理坐标映射（决策层）
5. 查表得到6个关节舵机目标角度
6. 串口发送角度指令至ESP32（通信层）
7. ESP32驱动PCA9685 → 舵机执行（执行层）
8. 机械臂抵达目标位置
9. 执行护理动作（除湿/香薰/UV消毒/夹取）
10. 动作完成 → 机械臂归位 → 等待下一指令

**关键说明**：步骤1至5在笔记本端完成，步骤6至9在ESP32端完成。二者通过串口（UART）通信，消息格式为JSON，包含目标角度数组与动作指令。

### 2.3 技术可行性验证阶段

#### 第一阶段：校赛阶段（技术可行性验证）

- **目标**：验证"视觉引导→机械臂逼近"的技术路径可行性
- **成果**：
  - 搭建3自由度亚克力机械臂实验平台
  - OV2640实现颜色识别（红蓝识别率≥90%）
  - 完成增量式视觉伺服盲搜控制（端到端平均耗时8.8秒，闭环成功率90%）
- **局限**：平台简陋，3DOF自由度不足，无法模拟真实衣物护理场景

#### 第二阶段：省赛阶段（原理样机搭建）

- **目标**：搭建金属结构实物，验证系统在真实安装环境下的运行能力
- **成果**：
  - 升级为6轴金属机械臂+单电机同步带滑轨平台
  - 完成运动学建模（D-H参数标定、正逆解推导、工作空间分析）
  - 实现预置动作序列自动执行（取放、伸展、归位）
  - 开发WiFi网页控制端，支持实时状态监控与指令下发
  - 批量测试闭环成功率：20次测试中18次成功（90%），平均端到端时间8.8秒
- **局限**：因硬件架构变动较大，视觉模块未能同步升级（OV2640分辨率不足），省赛演示采用预置轨迹开环模式

#### 第三阶段：国赛阶段（智能闭环升级）

- **目标**：实现从"预设动作"到"视觉驱动"的完整闭环，验证产品级技术方案
- **核心升级**：
  - **视觉升级**：从OV2640（320×240）升级为USB高清摄像头（720p），从HSV颜色识别升级为YOLOv8目标检测
  - **算力升级**：引入笔记本作为上位机，承担视觉处理与智能决策任务
  - **控制升级**：预置开环轨迹 → 视觉定位+查表映射+实时执行
  - **交互升级**：串口触发 → 自动连续检测+实时反馈

### 2.4 快换接口与机械臂协同总体设计

本系统快换接口采用主盘+工具盘分离式结构，主盘固定安装于机械臂末端法兰，工具盘集成各类功能执行头；机械臂负责空间定位、姿态调节与对位运动，快换接口负责机械锁紧、电气导通、气路/水路对接、信号传输。整体实现：

1. **机械定位**：高精度定位销+防呆结构，保证重复定位精度
2. **动力传输**：电源、控制信号、传感器信号一体化对接
3. **介质传输**：除湿气流、香薰雾化管路、熨烫蒸汽管路同步通断
4. **协同控制**：主控系统识别工具盘类型，自动切换对应运动参数与工作模式

## 三、机械系统设计与实现

整体机械系统由移动平台、六轴机械臂、多功能末端执行器和标准化快换接口四部分组成。机械臂安装于滑轨Y轴滑块上，在水平面内精确移动至工作位置；机械臂负责垂直升降与姿态调节，将末端执行器送达指定护理位。

> 注：3.1–3.3 所描述部件均已制作实物并完成联调。3.5为产品化阶段的概念设计，已完成结构方案选型与三维建模。

### 3.1 移动平台方案

移动平台为机械臂提供水平面内的移动能力，使其可覆盖更大范围的工作区域。本系统采用模块化底座设计，机械臂本体与视觉系统保持统一，根据不同安装场景选配相应移动方案：

#### 方案A：单滑轨平台（原型搭建方案）

适用于阳台、洗衣店挂杆等单侧直线布局场景。

- **结构**：单电机同步带传动直线滑轨模组 + 铝型材支撑
- **控制**：步进电机由ESP32输出脉冲与方向信号控制
- **保护**：两端限位开关实现原点校准与超程保护
- **行程**：根据安装场景定制

#### 方案B：龙门式双轴平台（产品设计方案）

适用于衣柜等平面覆盖场景。

- **结构**：两组平行导轨 + Y轴横梁组成龙门框架
- **传动**：滚珠丝杆配合直线导轨，重复定位精度≤±0.02mm
- **行程**：X轴1.0m~1.6m，Y轴0.5m

#### 方案C：移动小车（产品概念）

适用于服装店、商业空间等灵活移动场景。

- **结构**：麦克纳姆轮或全向轮底盘+自主导航
- **控制**：视觉导航/磁轨引导，与机械臂联动
- **特点**：任意位置可达，适合开放式商业空间

### 3.2 机械子系统

整体系统架构由四个部分组成：

1. **XY轴运动平台**：承载机械臂，在水平面内精确移动至工作位置
2. **Z轴/机械臂**：实现垂直升降、伸展，将末端执行器送达指定位置
3. **末端执行器**：执行除湿、香薰、夹取等操作
4. **控制系统**：接受指令，控制各部件协同运作

#### 3.2.1 XY轴丝杆平台

- **结构组成**：由两组平行布置的X轴丝杆模组、一组横跨其上的Y轴丝杆模组、步进电机及驱动器构成
- **传动方式**：滚珠丝杆（直径12mm，导程5mm）配合直线导轨，重复定位精度可达±0.02mm
- **驱动电机**：42步进电机（Nema 17），搭配A4988或TMC2209驱动器
- **行程参数**：X轴1.0m~1.6m，Y轴0.5m，两端安装限位开关用于原点校准及超程保护

#### 3.2.2 多自由度机械臂

- **关节配置**：采用3自由度串联结构（肩关节、肘关节、腕关节），各关节由大扭矩数字舵机（MG996R或类似，扭矩≥9kg·cm）驱动
- **臂长尺寸**：大臂与小腿长度均为150mm~200mm，完全伸展时末端可达衣柜深处（约400mm）
- **控制方式**：ESP32通过PWM信号控制舵机角度，可预置多个工作位姿
- **末端接口**：机械臂末端设计有标准快换接口，用于安装不同的末端执行器

#### 3.2.3 末端执行器

- **除湿模块**：基于半导体制冷片（TEC1-12706）设计，冷面贴合铝制散热鳍片配小型风扇强制对流，凝结水通过导流槽收集至可拆卸水盒。整体尺寸≤50×50×40mm，重量<100g
- **香薰模块**：采用微型超声波雾化片（频率1.7MHz）配合棉棒吸油芯，将液态香薰精油雾化为微米级颗粒。喷嘴设计为可转向结构
- **抓夹模块**：可简单执行抓取衣物的功能，使用SG90电机配合齿轮设计
- **集成方式**：将除湿模块和香薰模块集成在一个外壳内，模块整体通过舵机控制的卡扣与机械臂快换接口连接

#### 3.2.4 校赛方案

使用四自由度机械臂，SG90电机作为运动关节，亚克力板材作为结构材料：

- 关节1：控制机械臂整体旋转
- 关节2、3：控制在基于底面的铅垂面上运动
- 关节4：控制抓夹

### 3.3 视觉子系统

#### 3.3.1 补光与光学附件

- 补光LED：4~6颗白光贴片LED，由ESP32的GPIO控制
- 镜头选择：OV2640，焦距2.8mm，视角约66°
- 滤光片：移除红外截止滤镜，增加850nm红外补光灯，可用于夜间辅助成像

#### 3.3.2 硬件连接与安装

- **通信接口**：OV2640通过UART连接（TX/RX交叉），波特率115200
- **电源**：OV2640需5V供电，峰值电流约300mA
- **安装位置**：摄像头固定于XY轴滑台的Y轴滑块上，随机械臂底座一同移动

#### 3.3.3 硬件性能指标

| 参数 | 指标 |
|------|------|
| 图像传感器 | OV2640 (ESP32-CAM) |
| 有效像素 | 280万+ |
| 输出格式 | JPEG / BMP / RGB565 / YUV422 |
| 帧率 | 最高15 fps (800×600) |
| 工作电压 | 5V DC |
| 工作电流 | 180mA (无补光) / 300mA (补光全开) |
| 通信接口 | UART (115200 bps) |
| 补光方式 | 4颗白光LED + 可选2颗红外LED |

### 3.4 电气连接

- 由3010实验用电源供电
- 由PCA9685模块控制舵机，电机供电系统与PCA通信系统分离
- OV2640模块直接由ESP32-S3板上3v3引脚供电
- 继电器通过板载3.3v电源控制通过风扇的5v电源

### 3.5 末端快换接口概念设计

#### 3.5.1 结构方案选型

综合成本、加工难度、比赛实物可实现性，选用气动/弹簧自锁式手动+半自动快换接口，结构分为两部分：

1. **快换主盘（机械臂端）**：与机械臂末端输出法兰刚性连接，预留定位销孔、锁紧卡槽、导电触点、气路接口；内置弹簧锁紧机构
2. **工具盘（功能端）**：分别集成熨烫模组、UV消毒灯组、除湿吹风头、香薰雾化头、柔性夹持抓手；每个工具盘结构统一，可互换

#### 3.5.2 关键结构设计

- **定位机构**：2根圆柱定位销+防呆缺口，重复定位精度≤0.3-0.5mm
- **锁紧机构**：弹簧滚珠自锁结构，插入自动锁紧，按压解锁，换头时间＜2-3s
- **轻量化设计**：主体PLA/ABS 3D打印+铝合金标准件
- **防尘防水**：触点采用弹性防水铜针，气路密封圈密封
- **防误触**：设置机械保险扣，未完全对位无法锁紧

## 四、软件设计及实现

### 4.1 视觉识别

#### 4.1.1 图像预处理

- 输入图像缩放至固定分辨率（如320×320），保持宽高比并填充灰色边
- 归一化处理：像素值除以255，转换为0~1浮点数
- 可选增强：随机亮度、轻微旋转、裁剪（离线训练阶段）
- 感兴趣区域提取：根据机械臂工作范围提前裁剪，减少背景干扰

#### 4.1.2 特征提取

- 采用轻量级卷积网络（如MobileNetV3或EfficientNet-Lite）作为骨干
- 提取衣物类别特征：类别概率及边界框位置
- 提取颜色特征：在检测框内计算HSV颜色空间的主色调直方图
- 提取姿态/部位特征：利用关键点检测模型输出护理点坐标

#### 4.1.3 识别流程

摄像头采集一帧图像 → 送入预处理模块 → 轻量化模型推理 → 输出衣物类别、边界框、关键点坐标、颜色特征 → 结构化存储 → 将目标空间位置发送给机械臂运动学模块 → 触发后续护理动作。

#### 4.1.4 初赛视觉基础尝试

由于初赛阶段计算资源有限，将任务简化为识别特定颜色的正方形纸片（模拟部位），使用HSV阈值分割：

1. 将图像从RGB转换到HSV空间
2. 根据目标颜色设定HSV阈值范围，生成二值掩膜
3. 对掩膜做形态学开运算（去噪）
4. 提取轮廓，筛选面积最大且宽高比接近1的轮廓作为目标
5. 计算目标中心点像素坐标(u, v)
6. 根据偏差方向进行盲搜逐步逼近

### 4.2 机械臂软件控制

#### 4.2.1 驱动原理

使用Adafruit PWM Servo Driver Library，PCA9685频率设置为50Hz（SG90标准控制频率）。脉宽映射：SG90的0.5ms对应0度，2.5ms对应180度。

#### 4.2.2 位置映射（D-H参数）

创建`ArmKinematics`类，内部包含D-H参数矩阵：

- **正向运动学**：输入4个关节角度，计算出机械臂末端空间位置(X, Y, Z)
- **逆向运动学**：输入目标空间位置，计算出4个关节各应转到的角度

#### 4.2.3 运动学算法可视化验证

使用Python + NumPy + Matplotlib + SciPy进行运动学验证：

1. 建立虚拟环境，安装依赖
2. 定义DH参数表
3. 实现正向运动学（DH变换矩阵连乘）
4. 数值法求解逆运动学（`scipy.optimize.minimize`）
5. 3D可视化机械臂姿态

移植到ESP32-S3的注意事项：

- 矩阵运算：自己写简单的3x3/4x4矩阵乘法或使用轻量库
- 数值优化：建议针对四轴结构推导几何解析解，或实现轻量级雅可比伪逆迭代
- 也可以将PC上训练好的IK映射表存储为查找表（LUT）在ESP上使用
- ESP32-S3支持硬件浮点，直接使用`float`即可

### 4.3 数据库设计

衣物表记录：衣物ID、类别、颜色、位置（像素坐标或世界坐标）、录入时间等字段。

### 4.4 通信协议

系统通信分为三个层次：

- **用户端 ↔ 控制端**：手机APP/智慧屏 ↔ 树莓派（主控制器），协议HTTP + WebSocket，数据格式JSON
- **控制端 ↔ 执行端**：树莓派 ↔ 机械臂等执行器，通过串口（UART）或GPIO控制

- PWM1控制大臂俯仰
- 支持键盘实时控制各关节

#### 运动学分析

| 参数符号 | 含义 | 数值（mm） |
|----------|------|-----------|
| L₀ | 底座旋转中心距桌面高度 | 25 |
| L₁ | 大臂长度（肩关节至肘关节） | 100 |
| L₂ | 小臂长度（肘关节至末端中心） | 120 |

**正运动学**：采用几何法推导末端坐标（X, Y, Z），与底座转角θ₀、大臂俯仰角θ₂和小臂俯仰角θ₁的关系。

**舵机角度映射**：通过多组实测数据拟合得到线性映射式，在常用工作区域内预测误差小于±5mm。

**工作空间**：最大水平伸出距离约220mm，最大垂直举升高度约200mm，底座根部约30mm半径范围为不可达区域。

**逆运动学**：底座转角通过arctan2求解；平面内二连杆通过余弦定理求解；工程上采用增量式按键调节进行半自主控制。

**奇异位形与限位**：
- 边界奇异：θ₁接近0°或180°时，大小臂完全伸直或折叠
- 内部奇异：当末端投影R=0时（位于底座正上方）
- 关节限位通过`constrain()`函数硬性限定

#### ESP32-S3 PSRAM配置

发现ESP32-S3-N16R8开发板的PSRAM未被正确启用，原因是其16MB Flash使用Quad SPI (QIO)模式，8MB PSRAM使用Octal SPI (OPI)模式。解决方案是在`platformio.ini`中添加：

```ini
board_build.arduino.memory_type = qio_opi
board_build.psram_type = opi
board_build.flash_mode = qio
board_upload.flash_size = 16MB
board_build.partitions = default_16MB.csv
build_flags = -DBOARD_HAS_PSRAM
```

## 六、创新点与特色

### 1. 针对衣物部位级别的防潮干燥处理

传统衣柜只能整体除湿，无法处理腋下、领口等易出汗部位。本系统通过3自由度机械臂将半导体制冷除湿模块精确送至衣物指定区域（定位误差<5mm），实现局部冷凝排湿。结合视觉反馈，可主动识别并护理重点部位，大幅提升干燥效率。

### 2. 多功能末端执行器的紧凑集成

末端执行器将除湿（TEC制冷片+风扇）、香薰（超声波雾化片）、紫外线消毒（UVC LED）三种功能集成于50×50×40mm外壳内。通过快换接口与机械臂连接，支持按需切换护理模式。

### 3. 全闭环控制：视觉确认与数据库联动

系统不依赖开环示教。OV2640摄像头实时采集衣物图像，经颜色/形状识别后计算出目标位置偏差，驱动机械臂增量逼近直至对准。同时识别结果自动存入本地数据库，支持后续智能护理策略。

### 4. 低成本高集成：ESP32单芯片完成核心工作

初赛模型采用ESP32-S3（内置AI加速、16MB Flash、8MB PSRAM）作为唯一主控，同时运行图像采集、颜色识别、舵机闭环控制、Wi-Fi通信。无需树莓派或上位机，总硬件成本低于200元。

### 5. 多模态交互：语音与手势预留接口

除手机App远程控制外，系统预留离线语音识别模块（SU-03T）和手势传感器（PAJ7620）接口。

### 6. 多功能末端快换接口创新

采用标准化快换结构，实现多护理工具快速切换，突破传统衣物护理设备功能单一局限。

### 7. 机械臂-快换接口深度协同

实现机械定位、电气通断、气路集成一体化，完成多工序柔性自动化作业，提升系统集成度与智能化水平。
